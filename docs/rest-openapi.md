# REST delivery OpenAPI

MossCMS publishes the HTTP API as an OpenAPI 3.1 document generated by FastAPI. The reviewed copy is [`api/openapi.json`](../api/openapi.json). A running instance serves that same document at `GET /openapi.json` and renders it at [`/docs`](http://localhost:8001/docs).

The document describes editorial routes and the read-only delivery routes. Delivery reads published content for `Authorization: Bearer` with a delivery token. A session cookie or a token in the query string is rejected. `/delivery/graphql` stays a GraphQL POST. The other `/delivery` routes are GET and HEAD.

## Reviewed artifact

FastAPI builds the schema from the registered routes, response models, and the delivery notes added in `api/app/openapi_schema.py` (bearer scheme, query parameters, and cache headers). `api/tests/test_openapi.py` compares that schema with `api/openapi.json`. The test fails when they differ, including formatting, so an unreviewed route or model change does not land on its own.

Regenerate the file from the repository root after an intentional API change and review the diff:

```sh
cd api
MOSS_SECRET_KEY="$(printf 's%.0s' {1..40})" MOSS_SETUP_TOKEN="$(printf 't%.0s' {1..30})" \
  uv run python -c 'from app.main import app; from app.openapi_schema import OPENAPI_PATH, build_openapi, canonical_openapi; OPENAPI_PATH.write_text(canonical_openapi(build_openapi(app)))'
```

There is no committed GraphQL schema file. This OpenAPI document is the checked-in contract.

## ETag

`GET /openapi.json` and `HEAD /openapi.json` are public. They do not require a delivery token. Successful responses use the same helper as delivery reads:

- `Cache-Control: private, no-cache`
- `Vary: Authorization, Origin` from the delivery helper. CORS appends `Origin` again, so the header on the wire matches other delivery responses
- `ETag`: a quoted SHA-256 hex digest of `json.dumps(payload, sort_keys=True)` encoded as UTF-8

Send that exact `ETag` value back in `If-None-Match` to receive 304 with an empty body and no content type. `*`, a weak validator (`W/"..."`), and a list of validators do not match. HEAD hashes the document, not the empty body.

`/delivery/entries/{id}/resolved-assets` does not use this cache. Signed media URLs expire, so that route sends `Cache-Control: no-store` and no `ETag`.

## Delivery routes

| Path | Body |
| --- | --- |
| `GET /delivery/types` | Content types in the token's project, private fields removed |
| `GET /delivery/types/{typeKey}` | One content type |
| `GET /delivery/entries` | One page: `nodes`, `endCursor`, `hasNextPage`. `total` only when `total=true` |
| `GET /delivery/entries/{id}` | The published entry. Draft and schedule fields are null |
| `GET /delivery/entries/{id}/resolved-assets` | Signed image URLs. Not cached |
| `GET /delivery/website/redirects` | Former public paths for live entries in scope |
| `GET /delivery/website/reserved-paths` | Reserved path strings |

Query parameters on the list and item routes are in the OpenAPI document. Any other parameter is HTTP 422. The behavior matches [the REST delivery design](rest-delivery-design.md).

Interactive reference: open `/docs` on the CMS origin (Swagger UI) or `/redoc`. Both load `/openapi.json` from that origin.
